# Legacy — superseded Sentinel documents

These files are the project's earlier **Sentinel** incarnation ("Cyber Attack Path
Prediction and Risk Assessment Framework"). They are kept for history only and are
**no longer the plan**.

The project was re-centred to **ASCEND** (Attack-path Scoring and Chokepoint Evaluation
for Network Defence). The single source of truth is:

- `docs/ASCEND_Plan_of_Record.md` — the consolidated plan, reconciled against the code
- `docs/00_START_HERE_Index.md` … `docs/08_Base_Paper_and_Research_Narrative.md` — the ASCEND document set
- `docs/PLAN_RECONCILIATION_ASCEND_vs_Sentinel.md` — why ASCEND replaced Sentinel

Do not treat anything in this folder as current.
